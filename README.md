# The Prodigal Economy

**Financial simulation game inspired by the parable of the prodigal son.**

This interactive web app transforms Luke 15:11–32 into a modern financial journey. Players begin with a $50,000 inheritance and face increasingly tempting choices that affect not only their wealth, but also their integrity, relationships, health, and wisdom.

---

## 💸 Core Features

- Card-based decision system with real-time consequences
- Timeline visualization showing progress from prosperity to redemption
- Animated banking terminal interface with falling money effects
- Life stats tracking: Balance, Integrity, Relationships, Health, Wisdom
- Distinct game phases: Prosperity → Temptation → Crisis → Rock Bottom → Redemption

---

## 🙏 Biblical Integration

This game teaches:
- Financial ruin often stems from deeper spiritual issues
- Pride and instant gratification lead to crisis
- Redemption requires humility, not just money
- Grace is always available for those who turn back
